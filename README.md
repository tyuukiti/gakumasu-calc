# 学マス 育成ステータス理論値計算ツール

学園アイドルマスター（学マス）のサポートカード編成によるステータス理論値を計算するデスクトップツール＋Web版です。

## 利用方法

| 種別 | リンク |
|---|---|
| 🌐 Web版 | [tyuukiti.github.io/gakumasu-calc](https://tyuukiti.github.io/gakumasu-calc/) |
| 📦 デスクトップ版 | [Releases](https://github.com/tyuukiti/gakumasu-calc/releases) |

## ⚠️ 注意事項

- **持ち込みPアイテムによるステータス補正は含まれていません。** 表示される数値はサポートカード編成＋キャラ補正＋持ち込みメモリーによる理論値です。
- キャラクター選択を行うと、キャラ固有の基礎ステータス加算と属性別パラボ%を最終ステータスに反映します（未選択時はキャラ補正なし）。なお、デッキ最適化スコアにはキャラ補正は影響しません（全カード共通の加算/乗算で順位が保存されるため）。
- 持ち込みメモリー（最大4枚）の実数値加算・パラボ%もキャラ補正と同列に最終計算へ反映されます。プリセット保存にも対応しています。
- サポートカード付属のプロデュースアイテム効果によるステータス上昇は計算に含まれます（マウスオーバーで `[アイテム]` として内訳表示）。
- サポートイベントによるパラメータ上昇増加効果（+N%）も計算に反映されます。
- 所持カードモードでは凸数に応じた効果値で計算します。全カードモードでは4凸（完凸）前提で計算します。
- 3凸レッスンボーナス（課金要素）はデフォルトOFFで、UIから切替可能です。
- ステータス上限は育成プランごとに異なります（初レジェンド: 3000、NIAマスター: 2600、H.I.F: 3000＋本戦上限増加パネル）。

## アプリケーション構成

| プロジェクト | 説明 |
|---|---|
| **Web版** (`web/`) | ブラウザで動作する計算ツール＋所持管理（React + TypeScript） |
| **GakumasuCalc** | デスクトップ版メイン計算ツール（WPF） |
| **CardInventoryManager** | デスクトップ版サポートカード所持管理 |
| **SupportCardEditor** | サポートカードデータ編集（開発者用、配布版には含まれません） |

## 動作要件

### デスクトップ版
- Windows 10/11（64bit）
- .NETランタイムのインストールは不要です（同梱済み）

### Web版
- モダンブラウザ（Chrome, Firefox, Safari, Edge）

## 使い方

### 画面構成

Web版・デスクトップ版とも、シナリオごとのタブに分かれています（起動時は HIF を表示）。

| タブ | シナリオ |
|---|---|
| **HIF** | H.I.F (Hatsuboshi IDOL FESTIVAL) — 選抜試験(Day 1-20)＋本戦(Day 21-29) の29日構成 |
| **初レジェンド** | 初Legend — 18週構成 |
| **NIA** | NIA マスター — 26週構成、オーディション獲得パラメータ対応 |

Web版にはさらに「所持管理」「使い方」タブがあります。

### 基本フロー（全シナリオ共通）

1. **育成タイプを選択** — センス / ロジック / アノマリー
2. **日程（スケジュール）を設定**
   - 各週・各日の行動（レッスン / 授業 / おでかけ / 相談 など）を選択します。メイン属性は日程の選択内容から自動判定されます
   - **一括設定**: 全公開レッスンに同じメイン/サブ属性、全授業に同属性、試験配分プリセットなどを一括適用できます
   - **日程プリセット**: シナリオ別に名前付きで最大10件保存・呼び出しできます
3. **SP枚数を設定** — Vo / Da / Vi ごとのSPレッスン回数を指定します
4. **レッスン内イベント回数を設定**
   - テンプレート（活動支給軸 / 相談削除軸 など）を選ぶと推奨値が自動入力され、該当週の行動も自動で切り替わります
   - 「詳細を編集」を展開すれば個別に調整できます
   - 調整した回数は「マイプリセット」として名前付きで保存・呼び出し・削除できます（最大10件）
5. **必須カード / 除外カードを指定（任意）** — 特定のカードを必ず編成に含める、または候補から外せます
6. **キャラクターを選択（任意）** — キャラ固有の基礎ステータス加算と属性別パラボ%が結果に反映されます
7. **持ち込みメモリーを設定（任意）** — 最大4枚、各属性ごとに「実数値加算」または「パラボ%」を指定できます。プリセット保存対応
8. **「計算実行」をクリック** — 最適な編成パターンが複数表示されます

### シナリオ固有の設定

- **HIF**
  - **HIFボーナスパネル**: Vo/Da/Vi上昇 Lv1-5、本戦パラメータ上限増加 Lv1-6 など、所持パネルのLvを指定します
  - **MAX大幅超過時に再抽選**: 上限超過量が閾値を超えた編成にペナルティを与え、カード差し替えを促すオプション
  - 編成は Vo×2 / Da×2 / Vi×2 / オールフリーの4パターンを試行します
- **初レジェンド**
  - 5/8/11/13/15/17週で「休む」を選択できます（プロデュース中4回まで）。休む選択時に発動するサポートカード効果も計算に反映されます
- **NIA**
  - **オーディション獲得パラメータ**: 選択キャラの審査基準（バランス/突出）と流行1/2/3に応じて、獲得パラメータをVo/Da/Viへ自動振り分けします。オーディションごとに種別（FINALE/QUARTET等）を選択できます（キャラ未選択時は流行が不明なため獲得0）

### 結果の見方

- **編成パターン**: 各パターンに使用カードのレアリティ・属性・プランとステータス寄与値が表示されます
- **カード名にマウスオーバー**でステータス上昇の内訳を確認できます（イベントパラ上昇増加効果は `初期値+20(+100%)=40` のように補正後の値で表示）
- **アビリティまとめ（行動別）**: デッキ6枚の効果を行動（授業終了・レッスン終了・スキルカード獲得など）ごとに合算した一覧です。1発動あたりの上昇値・カード別内訳・発動回数・合計を確認でき、どの行動を優先すべきかを比較できます
- **週別内訳**: 各週（HIFは各日）の獲得ステータスをテーブルで確認できます
- 計算結果バーにはキャラ補正・メモリー補正分が暗色で可視化され、合計値の隣に補正なしの値も併記されます
- **診断コピー**: 設定と計算結果のダンプをテキストでコピーできます（不具合報告の際に添付いただくと調査がスムーズです）
- 所持カードモードでは、レンタル枠と所持枠の入れ替え検証も自動で行われます

### コンテストモード

コンテストメモリー作成用の編成を計算するモードです。「計算実行」横のチェックボックスでONにすると、スキルカード付き・コンテストアイテム付きのサポートカードを編成候補から除外して計算します（レンタル枠にも適用。必須カードに指定したカードは除外されません）。

### 所持カードの管理

- **Web版**: 「所持管理」タブ
- **デスクトップ版**: CardInventoryManager アプリ

1. カード画像をクリックして所持/未所持を切り替えます
2. 凸数をドロップダウンで選択します（0〜4）
3. フィルター（レアリティ/属性/所持状態）で絞り込みできます
4. 保存した所持情報は計算ツールの「所持カードのみで計算」オプションで利用されます（デスクトップ版は **Ctrl+S** または「保存」ボタンで保存）

## データ構成

```
Data/
├── SupportCards/   # サポートカードデータ (SSR/SR/R)
├── Plans/          # 育成プランデータ (hif / hatsu_legend / nia)
├── Templates/      # イベント回数テンプレート
├── Characters/     # キャラ定義 (基礎ステータス加算 / パラボ% / 3凸ボーナス / NIA審査基準・流行)
├── Images/         # カード画像 + マッピングファイル（画像は著作権の関係でリポジトリに含まれません）
└── Inventory/      # 所持情報 (自動生成)
```

各種プリセット（持ち込みメモリー / イベント回数 / 日程 / HIFボーナスパネル）は、デスクトップ版では `Data/` 配下に自動生成され、Web版ではブラウザの localStorage に保存されます。

YAMLデータ形式の詳細は [docs/data-format.md](docs/data-format.md) を参照してください。
