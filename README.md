# 学マス 育成ステータス理論値計算ツール

学園アイドルマスター（学マス）のサポートカード編成によるステータス理論値を計算するデスクトップツール＋Web版です。

## 利用方法

| 種別 | リンク |
|---|---|
| 🌐 Web版 | [tyuukiti.github.io/gakumasu-calc](https://tyuukiti.github.io/gakumasu-calc/) |
| 📦 デスクトップ版 | [Releases](https://github.com/tyuukiti/gakumasu-calc/releases) |

## ⚠️ 注意事項

- **持ち込みPアイテムによるステータス補正は含まれていません。** 表示される数値はサポートカード編成＋キャラ補正＋持ち込みメモリーによる理論値です。
- キャラクター選択を行うと、キャラ固有の基礎ステータス加算と属性別パラボ%を最終ステータスに反映します（未選択時はキャラ補正なし）。なお、通常モードのデッキ最適化スコアにはキャラ補正は影響しません（全カード共通の加算/乗算で順位が保存されるため）。
- 持ち込みメモリー（最大4枚）の実数値加算・パラボ%もキャラ補正と同列に最終計算へ反映されます。プリセット保存にも対応しています。
- プロデュースアイテム効果によるステータス上昇は計算に含まれます（マウスオーバーで `[アイテム]` として内訳表示）。
- サポートイベントによるパラメータ上昇増加効果（+N%）も計算に反映されます。
- 所持カードモードでは凸数に応じた効果値で計算します。全カードモードでは4凸（完凸）前提で計算します。
- 3凸レッスンボーナス（課金要素）はデフォルトOFFで、UIから切替可能です。
- ステータス上限は育成プランごとに異なります（初Legend: 3000、NIAマスター: 2600、H.I.F: 3000＋本戦上限増加パネル）。
- **H.I.F (Hatsuboshi IDOL FESTIVAL) モードは先行公開**です。イベント回数テンプレート、公開レッスンのサブ値、試験日の基礎値・配分値、HIFボーナスパネルの効果テーブルは暫定値で動作しています。今後のアップデートで数値を見直す予定です。

## 使い方

### 通常モード（Web版 / デスクトップ版共通）

1. **育成プランを選択** — 「初Legend」「NIA」などから育成プランを選びます
2. **育成タイプを選択** — センス / ロジック / アノマリーを選びます
3. **キャラクターを選択（任意）** — 選択するとキャラ固有の基礎ステータス加算と属性別パラボ%が結果に反映されます
4. **持ち込みメモリーを設定（任意）** — 最大4枚、各属性ごとに「実数値加算」または「パラボ%」を1値ずつ指定可能。プリセット保存対応
5. **属性設定を行う**
   - 各属性（Vo / Da / Vi）のメイン/サブを設定
   - SP枚数（属性ごとのSPカード枚数）を指定
6. **レッスン内イベント回数を設定**
   - テンプレートから選択すると推奨値が自動入力されます
   - 「詳細を編集」を展開すれば個別に調整可能です
7. **「計算実行」をクリック** — 最適な編成パターンが複数表示されます
8. **編成パターンを比較**
   - 各パターンには使用カードのレアリティ・属性・プランとステータス寄与値が表示されます
   - カード名にマウスオーバーでステータス上昇の内訳を確認できます（イベントパラ上昇増加効果は `初期値+20(+100%)=40` のように補正後の値で表示）
   - 所持カードモードでは、レンタル枠と所持枠の入れ替え検証も自動で行われます
   - 計算結果バーにはキャラ補正・メモリー補正分が暗色で可視化され、合計値の隣に補正なしの値も併記されます
9. **コンテストモード** — スキルカード・コンテストアイテム付きサポカを除外して計算できます

### H.I.F (Hatsuboshi IDOL FESTIVAL) モード（先行公開）

H.I.F は選抜試験(Day 1-20) + 本戦(Day 21-29) の29日構成イベント。通常プランと別の専用UIで扱います。

- Web版: ヘッダーの「HIF」リンクから `/hif` ページへ
- デスクトップ版: メインウィンドウの「HIF」タブ

1. **育成タイプ・キャラ・持ち込みメモリーを設定**（通常モードと同様）
2. **スケジュールを調整**
   - 公開レッスン日: メイン属性 + サブ属性を選択（例: Vo→Da、メイン+60 / サブ+20）
   - 授業日: Vo/Da/Vi のいずれか
   - 試験日: 基礎値 + Vo/Da/Vi 配分値を入力
   - **一括設定**: 全公開レッスンに同じメイン/サブ、全授業に同属性、試験配分プリセット（Vo/Da/Vi全振り/均等）を一括適用可能
   - **プリセット保存**: 名前付きで最大10件保存、ブラウザlocalStorage（Web版）または `Data/HifSchedulePresets/` （デスクトップ版）に永続化
3. **HIFボーナスパネルを設定** — Vo/Da/Vi上昇 Lv1-5、本戦パラメータ上限増加 Lv1-6 など、所持パネルのLvを指定
4. **「計算実行」をクリック** — Vo×2/Da×2/Vi×2/オールフリーの4編成パターンを試行

### CardInventoryManager（所持管理）

1. カード画像をクリックして所持/未所持を切り替えます
2. 凸数をドロップダウンで選択します（0〜4）
3. フィルター（レアリティ/属性/所持状態）で絞り込みできます
4. **Ctrl+S** または「保存」ボタンで所持情報を保存します
5. 保存した所持情報は計算ツールの「所持カードのみで計算」オプションで利用されます

## データ構成

```
Data/
├── SupportCards/         # サポートカードデータ (SSR/SR/R)
├── Plans/                # 育成プランデータ (hatsu_legend / nia / hif)
├── Templates/            # イベント回数テンプレート
├── Characters/           # キャラ定義 (基礎ステータス加算 / パラボ% / 3凸ボーナス / イメージカラー)
├── Images/               # カード画像 + マッピングファイル
├── Inventory/            # 所持情報 (自動生成)
├── MemoryPresets/        # 持ち込みメモリープリセット (デスクトップ版、自動生成)
├── HifSchedulePresets/   # HIFスケジュールプリセット (デスクトップ版、自動生成)
└── HifBonusLevels/       # HIFボーナスパネルレベル設定 (デスクトップ版、自動生成)
```

# Wikiからカードデータを同期（新規追加・値更新・アイテム効果抽出）

# 確認のみ（書き込みなし）
