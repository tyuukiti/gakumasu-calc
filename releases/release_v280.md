## What's Changed

### New Features
- **「アビリティまとめ（行動別）」を追加** (Web版 / デスクトップ版)
  - 選択デッキのサポカ6枚を、行動（授業終了・レッスン終了・スキル/メンタル/アクティブ獲得 など）ごとに合算した一覧を、デッキカード一覧の最後に表示します
  - 「授業終了 Vo+75 (45+30) ×6回 → +450」のように、**1発動あたりの上昇値・カード別の内訳・発動回数・合計**をまとめて確認できます
  - メンタルカードとアクティブカードのどちらを取ると合計パラメが伸びるか、といった**行動の取捨選択をパッと比較**できます
  - 同じ行動はまとめて表示し、グループ内は Vo → Da → Vi の順、行動間はその行動で得られる合計パラメの大きい順に並びます
  - ※ 装備（初期値 / SP率）・パラメータボーナスは行動の選択で変動しないため、本まとめには含めていません
