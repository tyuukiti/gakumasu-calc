## What's Changed

### New Features
- **HIFモードの試験配分プリセットに2分割を追加** (Web版/デスクトップ版)
  - 従来の「Vo/Da/Vi 全振り」「均等3分割」に加え、配分値を2属性で半分ずつ振り分ける **VoDa / DaVi / VoVi** の2分割プリセットを追加（端数は前者の属性へ）

### Improvements
- **試験配分プリセットのボタンUIを刷新** (Web版/デスクトップ版)
  - 全ボタンを「カラーインジケータ＋ラベル」の統一書式に揃え、全振り（単色ドット）／2分割（2色バー）／均等（グレー3バー）をグループ分けして表示。属性が一目で分かり、行全体の見た目を統一
