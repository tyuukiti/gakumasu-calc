## What's Changed

### New Features
- **STEP4パラメーターボーナスに対応** (通常計算 + HIF、Web版/デスクトップ版)
  - 一部キャラに開放される STEP4 のボーナス（基礎ステータス＋レッスンボーナス）を計算へ反映できるようになった
  - STEP4 が設定されているキャラを選んだときだけ「STEP4ボーナス込み」チェックボックスを表示（デフォルト ON）
  - 対象キャラ: 月村手毬 / 有村麻央 / 倉本千奈 / 篠澤広 / 秦谷美鈴 / 姫崎莉波

### Improvements
- **3凸 / STEP4 ボーナスの ON/OFF をキャラごとに保持するよう変更** (Web版/デスクトップ版)
  - これまでは全キャラ共通の設定だったため、キャラを切り替えても同じ ON/OFF が使い回されていた
  - キャラごとに独立して記憶するようにし、Web版はブラウザに保存（リロード後も維持）、デスクトップ版はセッション内で保持
