## What's Changed

### New Features
- **プロデュースアイテム効果対応**: プロデュースアイテム付きサポカのアイテム効果（ステータス上昇）を計算に反映。マウスオーバーで `[アイテム]` として内訳を表示
- **イベント回数テンプレート更新**: 集中・やる気・全力・強気カード獲得をテンプレートに追加
- **SEO改善**: メタタグ・OGP・robots.txt・sitemap.xml を追加
- **フッターリンク追加**: GitHub・X へのリンクを追加

### Data
- サポートカードにアイテム効果データを追加（SSR 6枚・SR 15枚）
- イベント回数の表示順を整理（好調→集中→元気→好印象→やる気→温存→全力→強気）

### Scripts
- `sync_wiki.py`: 早見表からアイテム効果を自動抽出・マージする機能を追加
