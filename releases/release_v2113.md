## What's Changed

### New Features
- **計算結果を X で共有できる「X で結果をシェア」ボタンを追加** (Web版)
  - HIF・初レジェンド・NIA の各タブで計算を実行すると、計算結果の右上（診断情報をコピーの隣）に表示されます
  - シナリオ・育成タイプ・キャラ・Vo/Da/Vi と合計・編成カードを本文にして X の投稿画面を開きます。投稿前に自由に編集できます
  - 本文は X の文字数上限に余白を残して収まるよう調整し、収まらないカードは「他N枚」と省略します。4凸は凸数を省き、3凸以下とレンタルは明示します

### Improvements
- **検索エンジン・SNS 向けにシナリオ別ページと OGP 画像を用意** (Web版)
  - `/hif` `/legend` `/nia` `/inventory` `/usage` に直接アクセスしたときに、ページごとの title・説明文を持つ HTML が返るようになりました（従来は 404 ページ経由で起動していました）
  - URL を X や Discord に貼ったときのカード画像として、計算結果画面のスクリーンショットを追加しました
  - sitemap.xml を全ページ分に更新しました
  - 画面の表示や操作は従来と変わりません
