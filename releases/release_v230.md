## What's Changed

### New Features
- **除外カード機能を追加** (通常計算 + HIF、Web版/デスクトップ版)
  - 編成の自動選出から特定のカードを除外できるようになった
  - カード名で検索して除外リストに追加すると、そのカードは候補からも所持枠・レンタル枠からも外れる
  - 「このカードは今回使いたくない」「手放す予定のカードを抜いた編成を見たい」といったケースで便利
- **診断情報コピー機能を追加** (通常計算 + HIF、Web版/デスクトップ版)
  - 現在の設定・選択編成・計算結果を平文でクリップボードへコピーするボタンを常設
  - 「計算結果が体感と違う」などの問題報告時に、編成・設定・結果をそのまま貼り付けて共有できる

### Bug Fixes
- **SP率カードが要求枚数に満たない場合の補充を保証**
  - SP回数を指定したとき、プールに十分なSP率カードがあるのに要求枚数より少ないSP率カードしか選出されないケースがあった
  - 選出の優先順位を「必須カード > SP枚数 > 編成パターン」に統一し、不足分を所持枠・レンタル枠のSP率カードで補充するようにした (Web版/デスクトップ版)
- **HIF本戦インターバルを選択肢なしの固定日に変更**
  - 本戦の相談/特別指導はユーザ操作でマスを踏んだ扱いにならず、サポートカード効果が発動しないため、該当日 (Day 28) を選択肢なし (計算対象外) の「本戦インターバル」固定表示にした (Web版/デスクトップ版)
