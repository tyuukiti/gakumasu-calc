## What's Changed

### New Features
- **HIF でカスタムPアイテム（ポーチ）を選択できるようになりました** (Web版/デスクトップ版)
  - HIFボーナスの下に「カスタムPアイテム（ポーチ）」欄を追加しました。色 → ぬいぐるみ → デコレーションの3段階を選ぶと、設定した日程をもとに各段階の発動日と回数を自動で数え、Pドリンク獲得・スキル(SSR)獲得・スキルチェンジ・スキル強化・スキル削除の回数としてイベント回数に加算します
  - 段階ごとの発動契機・効果・この日程での発動日を表で確認できます。日程の都合で発動しない段階は赤字で表示されます
  - イベント回数の個別設定には「（＋ポーチ N）」と自動加算分が表示されるので、手入力と二重に数える必要はありません
  - よく使う組み合わせはマイプリセットに保存できます。初期状態で「花ロボ 黄」「花もじゃ 黄」「メダルもじゃ 黄」の3つが登録されています
  - 全体プリセットと診断情報にポーチの選択が含まれます。X で共有したリンクを開いた人にも同じポーチ設定で結果が表示されます (Web版)

### Improvements
- **折りたたみ見出しの表示を統一** (Web版)
  - 個別調整・HIFボーナス・カスタムPアイテム・イベント回数の個別設定・キャラ選択・持ち込みメモリー・全体プリセットの見出しを同じ形にしました
  - 選択中のキャラやポーチの組み合わせなど現在の設定を見出しに表示し、未設定のときは「未選択」「未設定」と表示します
- **プリセット欄の表示を統一** (Web版)
  - スケジュールのプリセットをプルダウンからボタン一覧に変更しました。他のプリセット欄と同じく、ボタンを押すとその場で読み込まれます
  - 各プリセット欄の見出しを「マイプリセット」に揃えました
- **持ち込みメモリーの入力欄を見やすくしました** (Web版)
  - 入力表の間延びをなくし、他の欄と同じ囲いを付けました

### Fixes
- **NIA のオーディション欄でラベルが途中で折り返される問題を修正** (Web版)
