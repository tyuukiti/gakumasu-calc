## What's Changed

### New Features
- **「スキルカード獲得時」(汎用) トリガーに対応**
  - これまで「スキルカード（SSR）獲得時」「アクティブスキルカード獲得時」「メンタルスキルカード獲得時」などの specific 系のみマッピングされていたが、汎用「スキルカード獲得時」アビリティが未対応で計算に反映されていなかった
  - 例: 『基礎＞応用』Lv.10「スキルカード獲得時、ボーカル上昇」、『のんびり美味しいひととき』Lv.10「スキルカード獲得時、ビジュアル上昇」が正しく発動するようになった
  - イベント回数設定 UI に「スキルカード獲得」入力欄を追加 (Web版/デスクトップ版)
  - イベントカウントテンプレートにも `skill_acquire: 13` の初期値を追加

### Bug Fixes
- **HIFモードの編成ロジック改善 + 計算結果表示の cap 整合化** (#72)
  - MAX 表示閾値を `finalCapBonus` 込みの動的キャップに修正 (これまで cap 超過量が正しく扱えていなかった)
  - 計算結果の属性値・合計を cap 適用後の実効値で統一表示 (生数値は補足表示)
  - MAX 表示時のバー幅を統一し、cap 超過量を補足表示
  - レンタル候補から「ユーザ4凸所持」カードを除外 (rental upgrade 恩恵ゼロのため枠の浪費を防止)
  - postOptimize の合計同点時タイブレーカを追加 (raw_total の大きいカード優先)
  - レンタル含む deck 確定後に SP カードが spCounts を超過していた場合、余剰分の保護を外し非SPカードへの差し替えを許可
  - 「MAX 大幅超過時の再抽選」を HIF オプション化
- **SP率が設定されているカードのピックロジックを修正** (#70)
  - SP率効果を持つカードが、編成時に意図したとおりに選出されないケースを修正
- **最終計算結果時、レンタル枠のカードを所持していた場合に所持情報で計算していた問題を修正** (#69)
  - レンタル枠で選出されたカードが、ユーザの所持情報 (凸数等) で計算されてしまい、レンタル本来の値と異なる結果になっていた
- **一部 SR カードの凸別効果値が 0凸時点で 0 になっていた問題を修正**
  - 完凸値のみ Wiki に記載されているアビリティ (Lv.5 取得アビリティの一部) で、Wiki 取り込み時に先頭の空セルを 0 で埋めていたため `[0,0,0,0,N]` のような値になり、0凸時点では未発動扱いになっていた
  - 実ゲームでは Lv.5 取得アビリティは 0凸 (Lv.1〜20) でも発動するため、先頭の空セルは後ろの最初の有効値で埋めるよう修正
  - 影響カード: 『のんびり美味しいひととき』(SP_SR_0073) の 5 effect すべてを正しい値に再scrape
