## What's Changed

### New Features
- **X で共有したリンクを開くと、共有元と同じ計算結果がそのまま表示されます** (Web版)
  - 「X で結果をシェア」で投稿されるリンクに、結果を再現するための情報（シナリオ・日程・試験配分・HIFボーナスLv・育成タイプ・キャラ・SP枚数・イベント回数・持ち込みメモリー・6枚の編成と凸数）が含まれるようになりました
  - リンクを開いた人には、ページ上部のバナーに到達ステータス・合計・編成・条件が表示され、その下に通常の結果欄・編成パターン・選択デッキの内訳も共有元と同じ内容で表示されます。所持カードの登録は不要です
  - バナーの「この条件で自分の手持ちで計算」を押すと、共有元の条件（日程・育成タイプ・キャラ・SP枚数・イベント回数・持ち込みメモリーなど）を引き継いで、自分の所持カードで最適編成を計算できます
  - 共有結果を表示している間は、開いた人のキャラ選択・HIFボーナスLv・凸トグルの保存設定は変更されません。計算実行やタブ切替で通常の表示に戻ります
  - HIF・初レジェンド・NIA の全タブに対応しています。以前に投稿された従来形式のリンクもそのまま開けます

### Fixes
- **全体プリセットを読み込んでもイベント回数テンプレートのプルダウン表示が変わらない問題を修正** (Web版)
  - 回数の値自体は読み込まれていましたが、プルダウンの表示が「-- テンプレートを選択 --」のままでした。読み込んだテンプレート名が表示されるようになります
