## What's Changed

### New Features
- **コンテストモード**: スキルカード・コンテストアイテム付きのサポカを除外して計算するモードを追加（レンタル枠にも適用）
- **サポートカードにタグ追加**: 全カードに報酬種別（`skill` / `produce_item` / `exam_item` / `none`）を付与
