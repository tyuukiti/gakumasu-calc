## What's Changed

### New Features
- **スケジュール個別調整・週別内訳の表示領域をリサイズ可能に** (Web版/デスクトップ版)
  - スケジュール全体を俯瞰しながら設定できるよう、個別調整パネルの表示高さをドラッグで自由に変更できるようになりました（Web版はパネル右下のグリップ、デスクトップ版はパネル下端のつまみ）
  - 週別内訳（Web版）の表示領域も同様にリサイズできます
  - 変更した高さは保存され、次回以降も同じ高さで表示されます

### Data
- **雨夜燕のSTEP3ボーナスを反映** (Web版/デスクトップ版)
  - N.I.A編True Endボーナス（初期パラメータ Da+5/Vi+15、パラメータボーナス Vo+2.0%/Vi+1.0%）をキャラ補正値に加算しました
  - 燕を選択した際の計算結果に反映されます
