## What's Changed

### New Features
- 必須カード選択機能を追加（0〜4枚の必須カードを指定して計算可能）
- 未所持の必須カードはレンタル枠（4凸）として自動割り当て
- コンテストモードでも必須カードはフィルタを回避して編成に含まれる
