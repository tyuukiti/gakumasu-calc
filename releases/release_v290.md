## What's Changed

### New Features
- **HIFタブに「全体プリセット」を追加** (Web版/デスクトップ版)
  - スケジュール・試験配分・育成タイプ・SP枚数・イベント回数・必須/除外カード・持ち込みメモリー・キャラ選択の入力一式を、名前を付けて保存・呼び出しできます（最大10件）
  - プリセットの読込と同時に計算を実行するため、「Voレッスン全踏み」「Daレッスン全踏み」のような条件の比較がワンクリックで行えます
  - 保存した条件はブラウザの別タブやアプリの再起動をまたいで利用できます（Web版はブラウザ、デスクトップ版はDataフォルダに保存）
  - 場所は計算実行ボタンの上（持ち込みメモリーの下）の折りたたみセクションです
