## What's Changed

### New Features
- **必須カードの登録上限を4枚から6枚に拡張** (Web版/デスクトップ版)
  - W先生×Pアイテム3つなどでサポートカード5枚が確定する編成向けに、5枚を必須登録して残り1枠だけを自動選出に任せられるようになりました
  - 6枚すべてを必須指定すると、決め打ち編成の最終パラメータをそのまま確認できます

### Fixes
- **未所持カードがレンタル選出されず編成合計が理論値を下回る不具合を修正** (Web版/デスクトップ版)
  - 所持カードのみONのとき、未所持カード（所持管理で凸数が既定値4のまま保存されているカード）が「4凸所持＝借用の効果なし」と誤判定され、レンタル枠の候補から除外されていました
  - また、レンタル枠がSP率カードの借用で確定していると、未所持カードを借用して元のカードを所持0凸のSP率要員として残す入れ替えを探索できず、必須カード指定で作れる手動編成に自動編成が負けることがありました
  - どちらも修正し、未所持カードの借用を含む最適編成に到達するようにしました

### Data
- **新規サポートカード2枚を追加**
  - SSR「次の曲は〜ッあの曲だ！！」（Vo・ロジック）
  - SR「ずっしりスイカでりしゃす」（Da・ロジック）

  - 「ゆるるんあくび顔」に相談時のアイテム効果（Vi+10・Vi400以上）を追加
