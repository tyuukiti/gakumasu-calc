## What's Changed

### Bug Fixes
- デッキ最適化アルゴリズムを改善し、必須カード・SP率カード設定時に最適な編成が選ばれない問題を修正
- 結果コピー時の数値表示バグを修正（N288 → +288）

### New Features
- SP率カードにバッジ表示を追加（UI・結果コピーに [SP] マーク）

### Data
- 初レジェンドテンプレートの獲得カード枚数を修正（22枚 → 16枚）
