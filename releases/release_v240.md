## What's Changed

### New Features
- **イベント回数のマイプリセット保存機能を追加** (通常計算 + HIF、Web版/デスクトップ版)
  - 現在のイベント回数の入力値に名前を付けて保存・呼び出し・削除できるようになった（最大10件）
  - テンプレートの数値を自分の編成に合わせて調整したあと、その内容を残しておけるので毎回入力し直す必要がない
  - 通常モードとHIFモードでプリセットは共有

### Improvements
- **イベント回数テンプレートの初期値を見直し**
  - スキルカード獲得を20に統一し、カード種別ごとの内訳を調整（好調/集中、好印象/やる気/元気、温存/強気/全力 など）
- **イベント回数の入力欄の並びを整理** (Web版/デスクトップ版)
  - 「アクティブ獲得」を「アクティブ強化」の上に移動
  - デスクトップ版の通常モードのセクション順をHIFモードと統一（レッスン内イベント回数を持ち込みメモリーの後ろへ）
